## 👋 Quick Start for Beginners in Discord

1. **How to run Slash Commands (`/`)**:
   * Click the chat bar in any server channel and type **`/`**.
   * Start typing a command name (like `/rank` or `/kick`). Discord pops up a list—click the command you want.
   * Press **`Tab`** to move between options, then press **`Enter`** to send!
2. **What does `👁️ Only you can see this` mean?**
   * Some responses are **Ephemeral** (private). Only you see them inside the channel so chat doesn't get cluttered.
3. **Why does RookieBot say *"role equal to or higher than my highest role"*?**
   * Go to **Server Settings → Roles** and drag **RookieBot** above all member, color, VIP, and verified roles you want it to manage.
4. **Commands don't appear when typing `/`?**
   * Have a server Administrator type **`!sync`** in chat, then press **`Ctrl + R`** in Discord to refresh.
